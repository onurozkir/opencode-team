# Marketing and Launch

## 1. Positioning

One sentence, three parts:

> For **[target audience]**, **[problem solution]**, thanks to **[difference from the competitor]**.

Bad: "Our app is a modern, fast and user-friendly invoice tracking solution."
Good: "An invoice tracking tool for freelance graphic designers that automates email reminders, without QuickBooks' accounting complexity."

Test: can the target audience reading this sentence say "this is for me"? If not, narrow the target audience.

## 2. Message framework

| Layer | Content |
|---|---|
| Main promise | "[Problem] is now [outcome]" |
| Support 1 | Highlighted feature (in benefit language) |
| Support 2 | Trust signal (privacy, price, ease of setup) |
| Support 3 | Proof (user count, measurement, reviews — do not write it without proof) |
| Objection handling | "[Most likely objection] — [response]" |

Benefit language example: feature → "Cuts monthly billing from 2 hours down to 10 minutes."

## 3. Target audience

| Segment | Size | Where to find them | Budget | Priority |
|---|---|---|---|---|

Do not estimate the segment size; write "estimated".

## 4. Channel plan

Prioritize free or cheap channels. Order: owned channel (production) → community → direct outreach → partnerships → paid.

| Channel | Format | Frequency | Who | Metric | Priority |
|---|---|---|---|---|---|
| Reddit (relevant subreddit) | value-adding post | 1 per week | founder | comments + clicks | 1 |
| Product Hunt | launch page | launch day | founder | daily ranking | 2 |
| LinkedIn | short case study | 2 per month | founder | reach + site traffic | 3 |

For each channel: **what will be published** (format + message), **when**, **how success is measured**.

Do not advertise first. Start with the owned channel.

## 5. Landing page copy

```
[Headline] — the main promise, concrete
[Subheadline] — for whom, how
[Benefit list] — 3 items, each concrete
[How it works] — 3 steps
[CTA] — a single action ("Start free"), no second CTA
[Trust] — price, privacy, no card required
```

Rules:
- One CTA. If there are two buttons, one of them is not dominant.
- If "Try free" requires a card, do **not hide** this; it destroys trust.
- A benefit list, not a feature list.

## 6. Product announcement copy

Short. 100-150 words. What you do, for whom, how to get to it.

**Verify competitor names, prices and market data with `websearch`.** Do not make up data you could not verify; write "unverifiable".

## 7. Metrics

| Metric | Baseline | Target | Tool | When it is measured |
|---|---|---|---|---|

It must be measurable. Not "increase", but "a 25% increase" (relative to which metric?).

Tool suggestions (free): PostHog (1M events/month), Umami (self-hosted), GA4, Plausible CE, Cloudflare Web Analytics.

## Common mistakes

| Mistake | The right way |
|---|---|
| A feature list | A benefit list |
| Jargon ("solution", "platform", "ecosystem") | The user's own words |
| Made-up numbers ("10,000 users") | Do not write it without proof |
| 8 channels with no consistency in any of them | 2-3 channels, consistent |
| An unmeasurable target | Write a number or say "to be determined" |
| Making up the launch date | Say "proposed", put it in the list of open questions |
